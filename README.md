# Switch A2A Landing

Landing comercial de **Switch A2A**, una plataforma de orquestación inteligente para pagos cuenta a cuenta en Colombia, enfocada inicialmente en rieles como **Bre-B** y **PSE**.

La landing presenta el problema, la solución, el alcance de la Demo V1, el video demo funcional y el llamado a validación piloto con comercios, fintechs, PSPs o aliados estratégicos.

---

## Demo V1

La Demo V1 permite mostrar un flujo operativo completo de Switch A2A:

- Dashboard operativo.
- Payment Intents.
- Timeline por transacción.
- Simulator / Replay.
- Webhook Events.
- Webhook Deliveries / DLQ.
- Merchant Portal.
- Go-live checklist.
- Video demo funcional.
